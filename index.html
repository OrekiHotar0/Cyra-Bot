Cinq minutes pour te préparer

Le bot est conçu pour publier le rappel juste avant le début du cours. Le temps de vérifier où tu dois aller et de préparer tes affaires.

Les détails qui comptent

Matière, professeur, salle et horaires de début et de fin. Si la salle manque dans le planning, le rappel indique « Non communiquée ».

Un salon pour la classe

Les rappels sont regroupés dans un salon dédié. Chacun peut les consulter et choisir ses réglages de notification dans Discord.

Comment ça marche

Du planning au rappel.

La première version utilise le planning de BTS2 SIO SISR, préparé à partir d’un export Hyperplanning.

  1. 01 / LE PLANNING

    Les cours sont préparés

    L’équipe exporte le calendrier, vérifie les informations et les intègre au bot. Les mises à jour du planning sont actuellement manuelles.

  2. 02 / LE RAPPEL

    Cyra surveille les horaires

    Lorsque le bot est en service, il vérifie les prochains cours et prépare un rappel environ cinq minutes avant leur début.

  3. 03 / LA CLASSE

    Le message arrive sur Discord

    Le rappel est publié dans le salon configuré. Tu retrouves les informations du cours depuis ton ordinateur ou ton téléphone.

Ce qu’il faut savoir sur le fonctionnement de cette première version.

Le planning se met-il à jour automatiquement ?

Pas encore. Cyra Bot utilise les cours préparés depuis un export Hyperplanning. Lorsqu’un cours change, l’équipe doit actualiser les données du bot. Hyperplanning reste la source à vérifier en cas de doute.

Pourquoi une salle est-elle « Non communiquée » ?

Cela signifie qu’aucune salle exploitable n’était disponible dans les données du cours. Le bot affiche cette mention pour éviter de donner une information incorrecte. Vérifie alors le planning ou les indications de ton enseignant.

Puis-je l’utiliser pour une autre classe ?

La première version est configurée pour BTS2 SIO SISR à Ynov Lyon. Un autre groupe nécessite d’adapter le planning et le salon de destination. Une gestion de plusieurs classes ou serveurs fait partie des évolutions possibles.

Dois-je garder cette page ouverte ?

Non. Cette page présente le projet. Le bot fonctionne séparément, sur la machine qui l’héberge lorsqu’elle est en service. Les messages arrivent directement sur Discord ; tes alertes dépendent des réglages de notification du salon.
